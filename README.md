# My Portfolio Website

A small personal portfolio website built with HTML and CSS, consisting of three pages:

- **Home** — Landing page featuring a gallery of my photography.
- **Work** — A showcase of projects I've worked on, each linking to the live project or source.
- **About** — A short introduction about me, along with personal photos.

Each page shares a common header and footer containing my name and personal/contact information.

## Built With

- HTML5
- CSS3

## Pages

| Page  | Description                                   |
|-------|------------------------------------------------|
| Home  | Photo gallery / landing page                   |
| Work  | List of past projects with links                |
| About | Bio, personal photos, and contact info          |
